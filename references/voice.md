# Edit in the writer's voice

Use a named profile the author provides. If they provide samples, compare the
draft with samples written by the author for a similar audience and medium.
Keep useful habits you can point to: how they open, how they vary sentence
length, which contractions they use, and where they make room for humor or
an aside. Keep clear passages that already sound like them.
Use recurring habits to decide matters of style when the user has given you
room to choose.

If the author asks you to build a profile:

1. Use three to five samples when available. Prefer text the author wrote
   themselves. If the samples are too thin, label the profile provisional.
2. For each recurring habit, record a rule, a short original example and a
   version that breaks the rule. Distinguish general clarity from preferences
   that vary by writer, audience or medium. Treat a single occurrence as a clue.
3. Edit an unrelated short draft using the profile. Show the result so the
   author can correct your reading. Save a profile or sample excerpts only
   where the author asks you to put them.

Use this format for a profile.

- **Audience and medium.** Say where the profile applies.
- **Recurring habits.** Give each habit a rule, an example from a sample, and
  an example of a rewrite that would lose the habit.
- **Final check.** Turn the rules into a few questions you can answer from the
  revised text.

For example, suppose several team updates lead with the result and follow with
a short first-person sentence when the writer has a judgment to share.

- **Keep.** “The import took six minutes. I expected it to take twice that.”
- **Loses the cadence.** “The import took six minutes, which was half as long as I expected.”
- **Check.** Does the writer's judgment still get its own sentence?

On the last read, compare the revised passages with the profile or samples.
Check that you kept the writer's stance and cadence and that the new wording
still fits the audience. A profile can guide style. It cannot supply facts.

The profile format and practice edit draw on Henry Castro's Natural Voice.
