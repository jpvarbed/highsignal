# Highsignal: argument editing

Give writers an edit they can read straight through and a clear account of the
choices that matter. Keep one skill because both procedures protect the same
claims and voice. Infer which procedure to use from what the author asks for.
Argument editing starts with the reader's question and the evidence. Polishing
starts with the draft as written.

## Behavior

Method tier, standard effort. This change adds instructions and fixtures only.

- **Rewrite** handles polish, cleanup and voice requests. Return a clean draft
  and a brief note for substantial changes. Return only the draft when asked or
  when highsignal is one step in another workflow. An edit with no useful
  changes leaves the draft alone.
- **Edit** handles feedback on an argument, structure or reader experience.
  Read the whole draft before deciding what to change. Explain the apparent
  point, where the reader loses the thread, and what to do about it. Supply a
  coherent revision and exact before/after pairs for the consequential choices
  so the author can accept, reject or improve each one. For feedback only,
  show proposed replacements and leave the source alone. Google Docs
  Suggesting and comment threads are opt-in. A request to edit a live document
  follows the authorized scope and the document tool's access rules.
  If evidence only supports a narrower claim, show that wording as a proposal.
  Explain what evidence would justify the stronger claim.
- **Detect** quotes and explains issues without rewriting. Respect a requested
  copyedit or selection boundary. Use surrounding text to understand it.
- All modes protect the author's claims, scope, ranking, negation, uncertainty,
  conditions, voice and sources. Preserve quotes, code, link targets and other
  non-prose. Surface contradictions and unsupported leaps without resolving
  them by guesswork. Ask the one question that changes the edit if the draft
  gives no way to choose between materially different readings.
- Treat pattern matches as candidates. Preserve useful contrast, exact
  technical terms, deliberate rhythm and stance. Use an optional voice
  profile or supplied samples as evidence for choices about style. Read the
  final draft once more for new tics and lost meaning.
  Load the pattern catalogue for requested AI-style work. Ordinary polish
  starts with what the reader needs from the passage.
- For a polish, keep the original unless a specific passage causes a problem
  for its reader. Fix only what causes that problem. A note, headline, or
  social post may use shorthand that would need editing in a formal document.
- When a fix would change a claim or depends on missing evidence, tell the
  author what needs a decision. Use context to understand the original.
  Preserve the excerpt's claims when adding or substituting context.
- Compare meaning in both directions. An edit can keep the same words and
  change the ranking, denominator, or scope. For prose about a recent change,
  check that a reader who only knows the current draft can follow it.

## Evidence

- Use original fixtures for a buried argument, a real evidence conflict,
  a clean voice sample and feedback on a selected passage. Check each against
  the same rubric before and after loading the skill.
- Use two fresh readers from different model families for realistic tasks
  without exposing the rubric. Verify skill discovery where the host permits.
- Run the existing lens tests, check all new local pointers and review the
  spec and final wording. Keep failed or unavailable checks visible.
- Rerun the frozen 100 public excerpts against the same baseline. Target at
  most 10 meaning changes in actual edits, fewer unnecessary edits than the
  first run's 14, and no more missed edits than the first baseline's 12.
  Report each count and the useful responses. Preserve the first run.

The existing four review lenses stay in place. An optional voice reference
and the edit procedure load only when used. Credit all three upstream
projects in the README. The skill does not depend on their scripts or profiles.
